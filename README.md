# rynex-ai.# ⚡ Rynex AI - Code Assistant

AI-ассистент для программирования, работающий прямо в браузере через GitHub.

## 🚀 Быстрый старт (без установки!)

### Вариант 1: GitHub Pages (мгновенно)
1. Нажмите Fork
2. Включите GitHub Pages в Settings
3. Откройте https://[ваш-username].github.io/rynex-ai

### Вариант 2: GitHub Codespaces
1. Нажмите "Code" → "Open with Codespaces"
2. Запустите python -m http.server 8000
3. Откройте порт 8000

## 🔑 Бесплатные API ключи

### Hugging Face (рекомендую)
1. Зарегистрируйтесь на [huggingface.co](https://huggingface.co)
2. Создайте токен: Settings → Access Tokens
3. Вставьте в script.js в поле hf_ВАШ_ТОКЕН

### Cloudflare Workers AI (альтернатива)
1. Зарегистрируйтесь на [cloudflare.com](https://cloudflare.com)
2. Включите Workers AI
3. Скопируйте Account ID и API Token
